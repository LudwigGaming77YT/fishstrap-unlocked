Fishstrap: Unlocked is a fork of [Fishstrap][fishstrap] with the sole purpose of whitelisting content that is blacklisted in the original bootstrapper, while also sprinkling in a bit of extra customization

> [!NOTE]
> Like the original, Fishstrap is an application for **Windows 10 and above.**
> For other operating systems, such as Mac OS and various Linux distributions,
> you can try [AppleBlox][appleblox] and [Sober][sober] respectively.

## Added Features from Fishstrap (Not Much, I know.)

- Re-enabled Mesh Customization! Have fun with making or using custom body types to your heart's content!
- Added the Old Fishstrap and Old Bloxstrap Icons as an option, while also having the option to choose the newer ones as well!
